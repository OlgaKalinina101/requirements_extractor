✅ **Split Layout**: PDF слева + Requirements справа

✅ **Metrics Panel**: Покрытие документа + статистика по типам
✅ **Accept/Reject/Edit**: Полный workflow для review

## Как использовать

### 1. Загрузка документа
- Главная страница → "Загрузить документ"
- Выберите PDF
- Дождитесь обработки (будет real-time прогресс)

### 2. Review Interface
- После обработки → кликните на документ
- Откроется split view:
  - **Слева**: PDF viewer с навигацией
  - **Справа**: Список требований + фильтры + статистика + метрики

### 3. Работа с требованиями
- **Перейти к странице**: Кликните на чип "Страница N" в требовании
- **Принять**: Зелёная кнопка "Принять"
- **Отклонить**: Красная кнопка "Отклонить" (можно указать причину)
- **Редактировать**: Синяя кнопка "Редактировать" (изменить текст + причина)

### 4. Фильтры и статистика
- **Фильтры** (правая панель):
  - По статусу (Pending, Accepted, Rejected, Modified)
  - По типу (Техническое, Функциональное и т.д.)
- **Статистика**: Количество по каждому статусу
- **Метрики**:
  - Покрытие документа (% обработанных страниц)
  - Всего требований
  - Разбивка по типам
  - Пропущенные страницы

## Возможности PDF Viewer

- ⬅️ ➡️ **Навигация**: Кнопки вперёд/назад
- 🔢 **Прямой переход**: Введите номер страницы
- 🔍 **Zoom**: Кнопки + и - (масштаб 50%-200%)
- 📄 **Прямые ссылки**: Кликните на страницу в требовании

## API Endpoints (готовы)

- `GET /api/documents` - Список документов
- `GET /api/documents/{id}` - Данные документа
- `GET /api/documents/{id}/pdf` - **NEW!** PDF файл для viewer
- `GET /api/documents/{id}/requirements` - Требования документа
- `GET /api/documents/{id}/metrics` - Метрики покрытия
- `POST /api/requirements/{id}/accept` - Принять требование
- `POST /api/requirements/{id}/reject` - Отклонить требование
- `POST /api/requirements/{id}/edit` - Редактировать требование

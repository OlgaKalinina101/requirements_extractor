# Быстрый старт — работа с системой

## Запуск

### Docker (рекомендуется)

```bash
docker compose up --build
```

- **Frontend** → http://localhost:8080
- **Backend API** → http://localhost:8000/docs

### Локально

```bash
# Терминал 1 — бэкенд
python api_server.py

# Терминал 2 — фронтенд
cd frontend-vue && npm run dev
```

- **Frontend** → http://localhost:5173

## Сценарий использования

### 1. Создание проекта

- Главная страница → кнопка **«Создать проект»**
- Введите название и описание
- Проект появится в списке на дашборде

### 2. Загрузка и обработка PDF

- Откройте проект → **«Загрузить документ»**
- Выберите PDF-файл технического задания
- Выберите AI-модель (рекомендуется `claude-sonnet-4.5`)
- Нажмите **«Извлечь требования»**
- Наблюдайте за real-time прогресс-баром (10% → 100%)

Прогресс по шагам:
| % | Этап |
|---|------|
| 10% | Сохранение файла |
| 15–25% | Инициализация, парсинг PDF |
| 30–88% | AI-обработка страниц (обновляется пострйнично) |
| 90% | Сохранение в БД |
| 95% | Word-документ (если включён) |
| 100% | Готово |

### 3. Review требований

- Откройте обработанный документ → **«Открыть Review»**
- Split-view: PDF слева, требования справа
- Для каждого требования:
  - **Принять** — зелёная кнопка
  - **Отклонить** — красная кнопка (можно указать причину)
  - **Редактировать** — синяя кнопка (изменить текст + причина)
- Клик на «Страница N» → PDF автоматически переходит на эту страницу

### 4. Фильтры и метрики

- Фильтрация по статусу (Pending / Accepted / Rejected / Modified)
- Фильтрация по типу (Техническое, Функциональное и т.д.)
- Панель метрик: покрытие страниц, разбивка по типам, пропущенные страницы

### 5. Экспорт

Из карточки документа доступны ссылки:
- **Word (.docx)** — реестр требований с разбивкой по разделам и метриками
- **JSON** — машиночитаемый реестр
- **TXT** — текстовый отчёт

## API Endpoints

| Метод | URL | Описание |
|---|---|---|
| `POST` | `/api/auth/login` | Вход (email, password) |
| `GET` | `/api/auth/me` | Текущий пользователь |
| `GET` | `/api/users` | Список пользователей (admin) |
| `POST` | `/api/users` | Создать пользователя (admin) |
| `GET` | `/api/projects` | Список проектов |
| `POST` | `/api/projects` | Создать проект |
| `GET` | `/api/projects/{id}` | Детали проекта |
| `POST` | `/api/extract` | Загрузить PDF и запустить извлечение |
| `GET` | `/api/models` | Список AI-моделей |
| `GET` | `/api/documents` | Список документов |
| `GET` | `/api/documents/{id}` | Детали документа |
| `GET` | `/api/documents/{id}/requirements` | Требования документа |
| `GET` | `/api/documents/{id}/metrics` | Метрики покрытия |
| `GET` | `/api/documents/{id}/pdf` | PDF-файл для просмотра |
| `POST` | `/api/requirements/{id}/accept` | Принять требование |
| `POST` | `/api/requirements/{id}/reject` | Отклонить требование |
| `POST` | `/api/requirements/{id}/edit` | Редактировать требование |
| `POST` | `/api/requirements/{id}/assign` | Назначить исполнителя |
| `POST` | `/api/requirements/{id}/links` | Добавить связь |
| `GET` | `/api/requirements/{id}/history` | История изменений |
| `GET` | `/api/requirements/{id}/comments` | Комментарии |
| `POST` | `/api/comments` | Создать комментарий |
| `GET` | `/api/documents/{id}/export/word` | Экспорт Word |
| `GET` | `/api/documents/{id}/export/json` | Экспорт JSON |
| `GET` | `/api/documents/{id}/export/txt` | Экспорт TXT |
| `WS` | `/ws/logs` | WebSocket: real-time логи и прогресс |

Интерактивная документация API: http://localhost:8000/docs

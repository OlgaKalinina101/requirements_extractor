# Матрица прав по ролям

Документ описывает, какие действия доступны пользователям в зависимости от роли.

## Роли

| Роль | Описание |
|------|----------|
| **admin** | Администратор. Полный доступ ко всем функциям системы. |
| **manager** | Менеджер требований. Управление требованиями, проектами, загрузка документов. |
| **department_head** | Руководитель отдела по задачам. Те же права, что у менеджера (управление требованиями). |
| **user** | Исполнитель. Просмотр, комментарии, изменение статуса только своих назначенных требований. |

## Краткая сводка по ролям

| Роль | Ключевые возможности |
|------|------------------------|
| **admin** | Всё + управление пользователями, справочниками, просмотр активности и промптов |
| **manager** / **department_head** | Проекты, документы, требования (принять/отклонить/редактировать/назначить), загрузка, дашборд |
| **user** | Просмотр проектов, документов, требований; комментарии; смена статуса только своих назначенных требований |

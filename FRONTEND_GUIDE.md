# Инструкция по запуску веб-интерфейса

## 📋 Требования

- Python 3.11+
- Все зависимости из `requirements.txt`
- DeepSeek API ключ в `.env`

## 🚀 Быстрый старт

### 1. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Запустите API сервер:

```bash
python api_server.py
```

Сервер запустится на `http://localhost:8000`

### 3. Откройте веб-интерфейс:

Откройте в браузере файл:
```
frontend/index.html
```

Или используйте простой HTTP сервер:
```bash
cd frontend
python -m http.server 8080
```

Затем откройте: `http://localhost:8080`

## 💡 Использование

1. **Загрузите PDF файл**
   - Нажмите на область загрузки или перетащите PDF файл
   - Поддерживаются файлы до 50 МБ

2. **Начните обработку**
   - Нажмите кнопку "Начать обработку"
   - Наблюдайте за прогрессом в реальном времени
   - Смотрите логи DeepSeek AI в терминале

3. **Получите результаты**
   - После завершения появятся карточки с статистикой
   - Скачайте Word документ с реестром требований
   - Скачайте JSON файл и отчет о затратах

## 📊 Что входит в Word документ?

Word документ (`requirements_report.docx`) содержит:

1. **Реестр требований**
   - Все извлеченные требования
   - Разбивка по разделам
   - Таблицы с ID, текстом, типом и приоритетом

2. **Отчет о затратах**
   - Количество API вызовов
   - Использованные токены (input/output)
   - Общая стоимость в USD
   - Детализация по разделам

## 🔧 Конфигурация

### API Server (`api_server.py`)

Параметры можно изменить в коде:
- `host`: по умолчанию `0.0.0.0`
- `port`: по умолчанию `8000`
- CORS origins: сейчас разрешены все (`*`)

### Frontend (`frontend/index.html`)

API endpoints настроены на `localhost:8000`. Для продакшена измените:
```javascript
const API_URL = 'http://your-server.com:8000';
```

## 📁 Структура выходных файлов

Все файлы сохраняются в:
```
data/output/TIMESTAMP/
├── requirements_registry.json    # JSON реестр
├── table_of_contents.json       # Оглавление
├── usage_report.txt             # Текстовый отчет
├── requirements_report.docx     # Word документ ⭐
└── images/                      # Изображения из PDF
```

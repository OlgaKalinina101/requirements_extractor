# 1. Общие сведения

## 1.1 Цели и задачи проекта

Целью данного проекта является создание современной информационной системы управления проектами (ИСУП), которая позволит эффективно планировать, отслеживать и контролировать выполнение проектов компании.

**Основные задачи:**
- Разработка веб-приложения для управления проектами
- Обеспечение многопользовательского доступа с разграничением прав
- Интеграция с существующими системами компании
- Реализация системы отчетности и аналитики

**Требования к срокам:**
- Начало разработки: март 2026
- Завершение разработки: июль 2026
- Внедрение: август 2026

Система должна соответствовать ГОСТ 34.602-2020 "Информационные технологии. Комплекс стандартов на автоматизированные системы".

## 1.2 Назначение системы

Информационная система предназначена для:

1. **Планирования проектов** - создание и управление календарными планами, назначение задач исполнителям
2. **Контроля выполнения** - отслеживание прогресса, контроль сроков и бюджета
3. **Коллаборации** - обмен документами, комментариями и уведомлениями между участниками проекта
4. **Отчетности** - формирование отчетов о состоянии проектов, загрузке ресурсов, финансовых показателях

Система должна поддерживать одновременную работу не менее 100 пользователей. Время отклика на пользовательские действия не должно превышать 2 секунд при стандартной загрузке.

**Целевая аудитория:**
- Руководители проектов (30 пользователей)
- Участники проектов (60 пользователей)
- Руководство компании (10 пользователей)

Доступ к системе должен осуществляться через веб-браузер без установки дополнительного ПО. Система должна быть адаптирована для работы на мобильных устройствах.
